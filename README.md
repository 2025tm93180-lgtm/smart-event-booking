# Smart Event Ticket Booking System

A microservices-based event ticket booking system built with Spring Boot, MySQL, Apache Kafka, and the Saga pattern.

## Microservices

- Booking Service: Booking management and Saga orchestration
- Payment Service: Payment processing and compensation
- Event Service: Event information and availability
- Ticket Service: Seat reservation and ticket management

## Infrastructure

- MySQL
- Apache Kafka
- Docker
